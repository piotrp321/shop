# Instrukcje dla Codex

Przed rozpoczęciem pracy przeczytaj główny `CLAUDE.md` i stosuj jego zasady.
Przed pracą w danym obszarze przeczytaj również jego lokalny `CLAUDE.md`.
Ścieżki odnoszą się do worktree, w którym wykonujesz zadanie.

Claude Code prowadzi implementację. Domyślną rolą Codex jest analiza i review.
Zmieniaj kod wyłącznie na polecenie użytkownika. Nie nadpisuj zmian trwającej
sesji Claude Code; przed edycją sprawdź stan właściwego worktree.

Stan prac sprawdzaj w sekcji „Status” odpowiedniego planu funkcji
(`docs/features/<funkcja>/plan.md`), jeśli plan istnieje.
